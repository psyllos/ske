# ADR-012 — Réutilisation différée des analyses

## Contexte
Réutiliser un résultat sous une autre configuration peut produire une fausse preuve.

## Décision
Contrat v0.1 en cours : pas de déduplication de snapshots.
**Réutilisation d'analyses prévue v0.5, non implémentée** ; aucune avant v0.5.
Ensuite copie-sur-réutilisation avec provenance, jamais référence mutable partagée.

## Alternatives
Cache global immédiat par nom de fonction ou hash source seul ; fusion des imports.
Ces clés ignorent contexte, profil, toolchain et dépendances.

## Conséquences
Stockage supplémentaire accepté pour privilégier l'exactitude.
Le schéma futur et les clés de cache nécessiteront validation dédiée.

## Tests de non-régression
Prévus, non exécutés ici : deux imports égaux donnent deux snapshots ;
à terme changement de profil/contexte invalide le cache, copie indépendante.
