# ADR-004 — Stockage SQLite local

## Contexte
SKE vise un outil local portable, transactionnel et interrogeable en SQL.

## Décision
Contrat v0.1 en cours : SQLite est le stockage de référence unique.
Copier exactement la migration §8.2, 47 tables et 21 triggers ; WAL,
foreign_keys sur chaque connexion et contrôle des checksums de migration.

## Alternatives
Serveur de base de données ; fichiers JSON indépendants ; schéma simplifié.
Ils ajoutent de l'exploitation ou perdent le contrat d'intégrité normatif.

## Conséquences
Import atomique, migrations idempotentes, snapshots clôturés immuables
structurellement. Les FK seules ne couvrent pas l'intégrité inter-snapshot.

## Tests de non-régression
Prévus, non exécutés ici : schema_tables_match, migrations_,
connection_has_fk_on, rollback négatif, closed_snapshot_rejects_structural_writes.
