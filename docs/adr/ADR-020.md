# ADR-020 — Nil Go hors du contrat des littéraux CIR v1

## Contexte

§9.4 demande de préserver les `ssa.Const nil`. §4.4 définit `null_value`
pour les pointeurs/interfaces, pas pour SLICE, FUNCTION ni les types OPAQUE.
Une extension précédente admettait ces derniers par simple préfixe du
descripteur fourni par l'adaptateur. La revue a reproduit l'acceptation de
`go:map[` et `go:chan ` malformés, et de SLICE/FUNCTION non Go.

## Décision

Appliquer l'interprétation conservatrice de §0.3 et la frontière opaque de
§0.4 : le cœur n'accepte les littéraux nuls que pour POINTER, REFERENCE et
INTERFACE. Aucun descripteur libre ne permet d'étendre cette liste.

Pour les autres types Go nilables, conserver le vrai type et l'identité de
valeur, mais matérialiser une valeur SSA `OPAQUE_OP`, comme pour les autres
constantes non représentables en CIR v1. Émettre `OPAQUE_OP_EMITTED`
INFO/SYMBOLIC. Il s'agit explicitement d'une surapproximation, pas d'une
constante nulle exacte. Ne pas prétendre connaître ses propriétés de nullité.
La règle est générique, pas spécifique au laboratoire.

## Alternatives

- Accepter tous les préfixes `go:map[`/`go:chan ` : ne valide pas un type,
  élargit silencieusement la frontière de confiance ; rejeté.
- Convertir slices/maps/canaux/fonctions en POINTER : falsifie le type ; rejeté.
- Étendre le contrat public avec une représentation structurée des types
  nilables : évolution normative à traiter séparément, sans modifier
  silencieusement les schémas v1.

## Conséquences

Les inventaires structurels restent consultables avec leurs types réels.
L'analyse ne peut exploiter ces valeurs comme des nil exacts ; elle doit
traiter l'opération opaque et son diagnostic conservativement. Ce choix ne
change aucun schéma, migration, golden ni critère attendu, et ne constitue
pas une dérogation PASS/WAIVED d'un critère non exécuté.

## Tests de non-régression

- `cargo test -p ske-cir --test nil_trust` : tous les descripteurs usurpés,
  même bien formés, ne peuvent autoriser un littéral NULL OPAQUE/SLICE/FUNCTION.
- `go test ./internal/lower -run TestNilablesAndStrictCallSignatures` :
  types réels, nil POINTER/INTERFACE exacts, six autres nil explicitement opaques.
- `cargo test -p ske-cli --test go_review` : ingestion réelle, valeurs
  persistées, diagnostics INFO/SYMBOLIC, intégrité SQLite.
