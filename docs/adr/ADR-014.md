# ADR-014 — Constantes ValueDef et conversions explicites

## Contexte
Plusieurs représentations d'une constante compliquent validation et sémantique.

## Décision
Contrat v0.1 en cours : constantes dans ValueDef/LiteralValue, pas d'instruction
CONST ; pas de CAST générique. Employer les conversions typées du registre §4.3.

## Alternatives
CONST instruction doublonnant ValueDef ; CAST unique dépendant implicitement du
langage. Ces formes déplaceraient les ambiguïtés vers le moteur.

## Conséquences
Vérifier type, largeur et payload des littéraux et conversions.
Les constantes ne gonflent pas artificiellement les compteurs d'instructions.

## Tests de non-régression
Prévus, non exécutés ici : validation LiteralValue, vecteurs machine,
registre d'opcodes et compteurs exacts des fixtures.
