# ADR-007 — Exploration bornée et abstraction progressive

## Contexte
Boucles, récursion et embranchements empêchent une exploration concrète exhaustive.

## Décision
**Prévue v0.3, non implémentée** : exploration guidée par branches avec budgets
et coupes explicites ; analyse abstraite progressive prévue v0.4.

## Alternatives
Exploration sans borne ; prétendre qu'une profondeur fixe couvre tous les chemins.
La première peut ne pas terminer, la seconde invente une garantie.

## Conséquences
Une coupe empêche la fermeture globale requise pour une preuve.
Une abstraction doit conserver les comportements réels et déclarer ses hypothèses.

## Tests de non-régression
Prévus, non exécutés ici : boucles bornées/non bornées, budget épuisé,
run PARTIAL, cut_count non nul interdisant PROVEN_UNREACHABLE.
