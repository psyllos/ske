# ADR-011 — Contrôles SQL inter-snapshot

## Contexte
Les FK simples ne garantissent pas que les références appartiennent au bon snapshot.

## Décision
Contrat v0.1 en cours : conserver le DDL exact §8.2 et vérifier les invariants
inter-tables/inter-snapshot par les 22 contrôles SQL de ske db check (§8.5).

## Alternatives
FK composites (snapshot_id, id) partout. À reconsidérer si les contrôles sont
insuffisants, mais pas par modification silencieuse de la migration normative.

## Conséquences
Un import et un db check restent tous deux nécessaires ; FK activées ne
signifie pas intégrité complète. Rapporter chaque contrôle et ses violations.

## Tests de non-régression
Prévus, non exécutés ici : 22 entrées sans violation sur fixture saine ;
corruptions CHK-04/07/13/18 et cas d'activation CHK-22 ; exit 6 si corruption.
