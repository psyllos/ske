# ADR-017 — Profil et empreinte de build par unité

## Contexte
Un snapshot peut contenir plusieurs langages, cibles et configurations.

## Décision
Contrat v0.1 en cours : profil sémantique, SHA-256 hex du texte du profil et
empreinte de build portés par chaque unité, pas uniquement par le snapshot.
Profil des fixtures : go-fixture-linux-amd64.

## Alternatives
Profil global unique ; déduction depuis la machine de l'import.
Ces solutions confondent hôte et cible ou écrasent les différences entre unités.

## Conséquences
Les résultats futurs devront conserver ce contexte et leurs hypothèses.
Le multilangage reste prévu, non implémenté ici.

## Tests de non-régression
Prévus, non exécutés ici : hash recalculé indépendamment, changement de
configuration modifiant l'empreinte, fixtures au profil exact, négatifs de hash.
