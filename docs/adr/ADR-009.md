# ADR-009 — LLM post-analyse optionnel

## Contexte
Une formulation générée ne constitue pas une analyse structurelle ou une preuve.

## Décision
**Prévue v0.7, non implémentée** : enrichissement LLM facultatif après analyse
déterministe ; aucune règle LLM_INFERRED avant ce jalon.

## Alternatives
LLM dans l'import, la classification ou la preuve ; enrichissement obligatoire.
Ces solutions rendent la connaissance dépendante d'un modèle externe.

## Conséquences
Séparer origin (DETERMINISTIC, ABSTRACT_DERIVED, LLM_INFERRED) et
validation_status (UNVALIDATED, HUMAN_VALIDATED, REJECTED, STALE).
Une règle inférée ne remplace pas une règle déterministe.

## Tests de non-régression
Prévus, non exécutés ici : aucune sortie LLM en v0.1 ; à terme fonctionnement
sans fournisseur, provenance et validation distinctes, aucune promotion en preuve.
