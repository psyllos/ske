# ADR-008 — Inconnues explicites

## Contexte
Une traduction incomplète ne doit pas devenir une certitude artificielle (§3).

## Décision
Contrat v0.1 en cours : diagnostics et statuts distincts ; soundness
EXACT < OVERAPPROX < OPAQUE < UNSUPPORTED, dégradation monotone.
Le traitement symbolique prudent est prévu v0.3, non implémenté.

## Alternatives
Ignorer les opérations inconnues ; les traiter comme sans effet ; fusionner
inventaire, exécution et accessibilité. Ces choix cachent l'incertitude.

## Conséquences
Inventaire COMPLETE ne prouve pas une issue ; SAT n'est pas WITNESSED ;
UNKNOWN/TIMEOUT ne deviennent jamais inaccessibles.

## Tests de non-régression
Prévus, non exécutés ici : diagnostics obligatoires, dégradation COMPLETE,
issues UNANALYZED v0.1, interdiction SQL de WITNESSED.
