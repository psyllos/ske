# ADR-010 — Versionnement snapshot, profil et toolchain

## Contexte
Le même texte peut changer de sens selon cible, configuration et outils.

## Décision
Contrat v0.1 en cours : snapshots distincts, empreintes source/configuration,
profil et toolchain traçables par unité. Un futur run sera lié aux hypothèses
et versions de modèles ; ce run n'est pas implémenté ici.

## Alternatives
Identifier un résultat uniquement par le chemin source ou le commit ;
écraser le snapshot précédent. La reproduction serait ambiguë.

## Conséquences
Deux imports identiques produisent deux snapshots avec empreintes identiques.
Clôture structurelle immuable ; latest doit être désambiguïsé entre dépôts.

## Tests de non-régression
Prévus, non exécutés ici : fingerprints_ recalculés indépendamment,
double import, résolution latest et refus d'écriture sur snapshot clôturé.
