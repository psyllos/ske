# ADR-006 — Solver et ScriptedSolver

## Contexte
Le moteur futur doit être testable sans dépendre des variations du solveur réel.

## Décision
**Prévue v0.3, non implémentée** : interface Solver, backend Z3 et
ScriptedSolver pour réponses pilotées ; aucun accès aux sources ou au stockage
dans solver (§2.2).

## Alternatives
Appeler Z3 directement depuis l'exploration ; utiliser uniquement un faux
solveur. Le premier couple les couches, le second ne valide pas l'encodage.

## Conséquences
Séparer tests de contrôle et tests SMT réels. Z3 5.1.0 présent n'est pas une
intégration. UNKNOWN et TIMEOUT restent explicites.

## Tests de non-régression
Prévus, non exécutés ici : SAT/UNSAT/UNKNOWN/TIMEOUT scriptés, rejeu SMT réel,
budgets et interdictions de dépendances.
