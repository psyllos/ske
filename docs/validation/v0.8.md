# Validation v0.8 — scénarios causaux et documentation fonctionnelle

Source : ADR-024 et §7.5 (scénarios/capacités), §1.1 (connaissance
fonctionnelle). Commande autoritaire : `cargo test -p ske-cli --test scenarios_docs`.
Aucun AC normatif §19 v0.8 n'existait dans la spec v1.4 ; ce jalon est une
extension demandée par le commanditaire, documentée par ADR-024. La
non-régression reste gouvernée par les jalons v0.1–v0.7.

## AC v0.8 (5 tests d'intégration, sur adaptateur Go réel via `go_support`)

| # | AC | Commande | Résultat |
|---|---|---|---|
| AC-0.8-01 | Lien CALL CONFIRMED et idempotent entre scénario d'entrée et scénario de callee reconstruit | `scenario_link_is_confirmed_and_idempotent` | PASS : 1 lien `CALL` pour `Entry→helper`, `confidence=CONFIRMED`, re-link ne duplique pas ; `db_check` ok |
| AC-0.8-02 | Un callee non reconstruit n'est jamais inventé | `scenario_link_reports_unreconstructed_callee` | PASS : `links=[]`, `not_reconstructed=["example.helper"]`, `total_callees=1` |

| AC-0.8-04 | `docs render` : fiche déterministe, run autoritatif dédupliqué, preuve d'inaccessibilité rendue | `docs_render_writes_fiches_with_authoritative_dedup` | PASS : `Check` 3 cas (pas 6 après double reconstruction), `Decide` montre `x<0` et `MODEL_UNREACHABLE` |
| AC-0.8-05 | Pas de fiche sans comportement reconstruit | `docs_render_skips_functions_without_behavior` | PASS : `written=0` sur snapshot sans reconstruction |

## Preuves clés (sorties réelles de la campagne)

- `scenarios link --entry example.Entry` →
  `{"links":[{"callee":"example.helper","scenario_id":N,"confidence":"CONFIRMED"}],
    "not_reconstructed":[]}` ; re-exécution → encore 1 lien (idempotence).
- `scenarios show --entry example.Entry --depth 2` → arbre : `Entry`
  (2 cas : `a > 100 → return 1`, `a <= 100 → return 0`) → `example.helper`
  (2 cas propres), aucune frontière inventée.
- `docs render --out …` sur `example.Check` → fiche de **3 cas** (le run
  autoritatif), avec ancres `check.go:10/13/15`, statut `UNVALIDATED`,
  origine `DETERMINISTIC` ; la fiche `example.Decide` contient la section
  « Branches dont l'inaccessibilité est prouvée » (`ALL_ARRIVALS_UNSAT`,
  `MODEL_UNREACHABLE`, Z3 5.1.0.0).

## Ce qui n'est PAS couvert (frontières assumées, ADR-024)

- Scénario **interservice** (EVENT/HTTP/MESSAGE/PERSISTENCE) : non émis en
  v0.8 ; le schéma les accepte déjà, la construction est un chantier futur.
- `functional_capabilities.title` : reste `NULL` (dénomination métier humaine
  ou LLM, jamais automatique).
- Aucune interprétation métier dans les fiches (AC-0.5-08 respecté).

## Non-régression

- `cargo test --workspace` : **376 PASS, 0 FAIL** (inclut la suite
  `scenarios_docs` et tous les jalons antérieurs).
- `cargo fmt --all -- --check` : propre. `cargo clippy --workspace
  --all-targets -- -D warnings` : propre.
- Les validateurs v0.1–v0.7 restent la référence des jalons antérieurs ; cette
  campagne n'introduit aucune migration ni modification de schéma.
