- AC-0.7-10 : la « représentation structurée » est une récupération par faits
  structurés (`cfg` + `branches`), pas une génération LLM. La qualité/rappel
  LLM générale n'est pas mesurée (aucun token dépensé) : le rapport le déclare
  explicitement `quality="NOT_MEASURED: no LLM"`. L'exactitude est qualifiée
  « PARTIAL LAB inventory ; lexical retrieval is not semantic soundness ».
- AC-0.7-06 : l'adapter Query qui matérialise le graphe règle→cas→issues→
  preuves reste une intégration future ; la sélection structurelle est testée
  sur un graphe synthétique.
- AC-0.7-08/09 : transport HTTPS réel (hors loopback) non testé (aucun réseau
  dans la campagne) ; le mock loopback teste le protocole et la confidentialité.
- Le marqueur `verify.sh` est maintenant `VERIFY OK v0.7` ; les validateurs
  v0.5/v0.6 acceptent la propagation `v0.[1-7]` pour la chaîne de régression.
